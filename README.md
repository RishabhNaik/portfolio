# Rishabh Naik - Portfolio

Modern personal portfolio and digital art showcase built with **Next.js (App Router)**, **TypeScript**, and **CSS**.

## 🚀 Features

- **Home Page**: Hero introduction banner, "What can I do for you?" services section, and "Familiar with" tech stack badges.
- **Blog Section**: Dynamic markdown-based blog engine with articles, reading times, tags, and rich formatting.
- **Gallery**: Visual portfolio featuring Sushiksha cohort portraits and digital artworks with a fast interactive lightbox preview modal and search filter.
- **Contact Page**: Office contact cards (Phone, Email, Location), social profile directory (LinkedIn, GitHub, Instagram, Twitter, Cosmix), and interactive contact message form.
- **SEO & Performance**: Optimized static site generation (SSG), OpenGraph metadata, fast asset loading, and mobile responsiveness.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS & CSS Variables
- **Icons**: [Lucide React](https://lucide.dev/)
- **Markdown**: [Marked](https://marked.js.org/)

## 🏃 Getting Started

Install dependencies:
```bash
npm install
```

Run local development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view your portfolio in the browser.

## 📦 Build for Production

```bash
npm run build
npm start
```
